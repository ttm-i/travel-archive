# Travel Archive 操作ガイド

公開先: https://ttm-i.github.io/travel-archive/

## インストールと更新

1. iPhoneのSafariで公開先を開く。
2. 共有メニューから「ホーム画面に追加」を選ぶ。
3. 初回はオンラインで一度起動し、オフライン利用の準備完了を確認する。

更新案内が表示された場合は、先に最新のZIPバックアップがあることを確認してから更新します。アプリの更新でIndexedDBの旅行・写真を削除することはありませんが、SafariのWebサイトデータ削除や端末故障に備えて定期的にバックアップしてください。

## 最初の記録

1. 地図画面の「最初の旅行を作る」または旅行タブの追加ボタンを押す。
2. 旅行名、同行カテゴリ、期間、訪れた都道府県を入力して保存する。
3. 旅行詳細の「追加」からスポットを登録する。
4. 座標は数値を直接入力するか、地図で位置を合わせて確定する。
5. 1枚以上の写真を選び、必要ならメイン画像と順序を変更して保存する。

登録したスポットは、地図・旅行・都道府県の各タブから閲覧できます。同じスポットを別の旅行でも訪れた場合は「登録済みから」を選ぶと、スポットを重複させずに旅行との関連を追加できます。

## スポット写真の整理

- スポット詳細で大きな写真または写真一覧を押すと、全画面ビューアが開きます。
- 写真が2枚以上ある場合は、表示中の写真を「メインに設定」できます。メイン画像はスポット詳細と各一覧のサムネイルに共通で使われます。
- 「削除」は表示中の写真だけを端末から完全に削除します。バックアップがなければ元に戻せません。
- スポットには写真が1枚以上必要なため、最後の1枚は削除できません。
- メイン画像を削除した場合は、残っている写真が自動的にメイン画像になります。

## スポットの編集

スポット詳細上部の「編集」から、名称・カテゴリ・座標・写真を編集できます。

- 名称・カテゴリ・座標はスポット共通の情報で、関連するすべての旅行に反映されます。
- 都道府県は複数旅行で共有したときの不整合を防ぐため、スポット編集では変更できません。
- 座標の判定結果が登録都道府県と異なる場合は警告を表示します。
- 写真欄のプルダウンで旅行を選ぶと、その旅行に紐づく写真だけを表示します。
- 旅行詳細から開いた場合はその旅行、それ以外から開いた場合は関連旅行のうち開始日が新しい旅行を最初に選びます。関連旅行が1件なら選択は固定です。
- 写真の追加・並べ替え・削除は旅行ごとに行い、旅行を切り替えても保存前の変更は保持されます。
- 既存写真の削除は「変更を保存」した時点で確定します。

## 旅行の表紙

旅行作成・編集画面の「旅行の表紙」から設定します。

- 「登録画像から」では、その旅行に属するスポット写真を選べます。新規旅行では、旅行とスポットを一度保存した後に利用できます。
- 「カメラロールから」では、スポットとは独立した表紙専用画像を保存します。
- 「切り取りを調整」では「旅行一覧」と「旅行詳細」を切り替え、写真をドラッグして位置を、スライダーで拡大率を調整します。
- 「既定に戻す」と、旅行内の最初のスポット画像を自動使用します。写真がなければ従来の既定色で表示します。
- 登録画像を表紙にした後、その写真またはスポットを削除した場合は既定表示へ戻ります。

## 都道府県の表紙

都道府県詳細の上部にある「表紙」から設定します。

- その都道府県のスポット写真、またはカメラロールの写真を1枚選べます。
- 同じ写真を都道府県一覧のサムネイルと、都道府県詳細のタイトル画像に共通使用します。
- 「表示位置を調整」で「都道府県一覧」と「都道府県詳細」を切り替え、それぞれの比率に合わせて位置と拡大率を調整できます。
- 「既定に戻す」と、詳細は従来の単色表示、一覧は従来のスポット画像表示へ戻ります。
- 登録画像を表紙にした後、その写真を削除した場合は既定表示へ戻ります。

## 削除と復元

- 旅行は旅行詳細上部のゴミ箱ボタンからゴミ箱へ移動します。
- スポットと旅行の関連は、スポット詳細の「訪れた旅行」にあるリンク解除アイコンから外します。
- 設定の「ゴミ箱」から復元または完全削除できます。
- 完全削除後に戻すには、削除前のバックアップが必要です。

## バックアップ

1. 設定タブの「バックアップを作成」を開く。
2. 「完全バックアップを作成」を押す。
3. iPhoneの共有画面で「ファイルに保存」を選び、iCloud DriveなどへZIPを保存する。

共有画面を閉じただけの場合は保存完了として記録されません。設定に「バックアップしていない変更があります」と表示されたら、新しいZIPを保存してください。

復元は「バックアップから復元」でZIPを選び、表示された旅行・スポット・写真の件数を確認してから実行します。現在のデータはバックアップ内容で置き換わります。

## オフライン利用とデータ保護

- 初回表示とアプリ更新時には通信が必要です。それ以外の登録・閲覧・地図・バックアップはオフラインで使えます。
- 記録と写真はこのPWAを開いたiPhone内に保存されます。
- Safariの履歴とWebサイトデータを削除した場合、端末内の記録も失われる可能性があります。
- アプリを削除する前や端末を変更する前は、必ず最新のZIPバックアップを保存してください。
- 保存容量の警告が表示された場合は、先にバックアップを作り、不要なデータを整理してください。
