# Travel Archive 初版総合確認チェックリスト

初版の最終確認は、問題が起きた場合に原因を切り分けやすいよう4回に分けます。各回の確認結果を受け取ってから次へ進みます。

## 共通の事前準備

1. 設定タブで未バックアップの変更がないか確認する。
2. 最新の完全バックアップZIPを「ファイル」アプリへ保存する。
3. ZIPのファイル名と保存場所を確認する。
4. 総合確認中も、Safariの「履歴とWebサイトデータを消去」は行わない。

## 確認A: 更新後のデータ保持と基本オフライン動作

状態: 完了（2026-10-24）

目的は、GitHub Pagesからの更新後も既存データが維持され、通信なしで主要な記録を閲覧できることの確認です。

1. オンラインでホーム画面のTravel Archiveを起動する。
2. 既存の旅行数、代表的なスポット名、写真が表示されることを確認する。
3. 設定タブに更新案内がある場合は更新し、アプリを開き直す。
4. 手順2と同じ旅行・スポット・写真が残っていることを確認する。
5. アプリを終了し、iPhoneを機内モードにする。Wi-Fiもオフであることを確認する。
6. ホーム画面からアプリを再起動する。
7. 地図、旅行、都道府県、設定の4タブを一巡する。
8. 旅行詳細、スポット詳細、全画面写真をそれぞれ1件開く。
9. 日本地図を拡大縮小し、訪問県の色、ピン、クラスタが表示されることを確認する。
10. 機内モードのままアプリを終了し、もう一度起動できることを確認する。

確認結果として、次の3点を知らせる。

- 既存データと写真がすべて残っていたか
- 機内モードで再起動できたか
- 地図・写真を含む各画面に異常がなかったか

## 追加確認: PWAの左端スワイプバック

確認Bへ進む前に実施する。ホーム画面から起動したPWAでのみ有効になる。

1. 旅行詳細の左端から右へスワイプし、画面が指に追従して旅行一覧へ戻ることを確認する。
2. スポット詳細を旅行から開き、左端スワイプで元の旅行詳細へ戻ることを確認する。
3. スポット詳細を都道府県から開き、左端スワイプで元の都道府県詳細へ戻ることを確認する。
4. 都道府県詳細の左端から右へスワイプし、都道府県一覧へ戻ることを確認する。
5. 短い距離で指を離すと、詳細画面へ戻って操作が取り消されることを確認する。
6. 左端付近で縦にスクロールしても、前の画面へ戻らないことを確認する。
7. 写真ビューアや地図を操作しても、スワイプバックが誤作動しないことを確認する。

## 確認B: オフラインでの登録・編集・削除・復元

確認Aの完了後に実施する。機内モードのまま確認用の旅行とスポットを作成し、名称・カテゴリ・座標・写真の編集、旅行との関連解除、ゴミ箱からの復元を一巡する。

## 確認C: バックアップ全置換復元と写真量

確認Bの完了後に実施する。新しいZIPを保存し、件数表示を記録したうえで全置換復元を確認する。複数写真の一覧、全画面表示、保存容量表示、操作速度も確認する。

## 確認D: iPhone表示設定と初版承認

確認Cの完了後に実施する。文字サイズ、「視差効果を減らす」、縦画面のセーフエリア、画面遷移を確認する。確認A〜Dで重大な問題がなければ初版完了とする。
