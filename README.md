# Travel Archive

日本国内の旅行を、地図・旅行・都道府県の3方向から振り返る個人用PWAです。

## 現在の状態

初版の総合確認版です。旅行・スポット・写真・オフライン地図に加え、ゴミ箱と完全バックアップ・復元を利用できます。

- 同行・スポットカテゴリを作成、名称変更、並べ替え、削除できます。
- 旅行名、同行カテゴリ、日付、複数都道府県をIndexedDBへ保存・編集できます。
- 新規旅行の入力途中は下書きとして自動保存されます。
- 新規スポットは名称、座標、都道府県、1枚以上の写真を保存します。
- 写真は端末内で縮小・JPEG圧縮し、一覧用サムネイルも作成します。
- 同じスポットを別旅行から再利用し、Spotを複製せずVisitを追加できます。
- 日本地図、旅行、都道府県の3つの入口から同じスポット記録を閲覧できます。
- 一度オンラインで読み込むと、通信なしでも現在の画面を起動できます。
- 写真を含むZIPバックアップは端末内で作成され、完全バックアップに加えて期間・同行カテゴリで絞り込む条件付きバックアップを利用できます。復元前に種別・件数・形式を検証します。
- 設定画面では未バックアップの変更と、ブラウザが報告できる保存容量を確認できます。
- 旅行の表紙は、旅行内の登録画像またはカメラロールから選び、一覧用と詳細用の切り取りを個別に調整できます。
- 都道府県の表紙も、登録画像またはカメラロールから選び、一覧サムネイル用と詳細タイトル用の切り取りを個別に調整できます。
- スポット詳細から名称・カテゴリ・座標を編集し、関連旅行を選んで写真を旅行ごとに追加・並べ替え・削除できます。

基本操作とバックアップ時の注意は [操作ガイド](docs/user-guide.md) にまとめています。
初版完成前の確認項目は [初版総合確認チェックリスト](docs/final-acceptance-checklist.md) にまとめています。

## 公開

アプリ: https://ttm-i.github.io/travel-archive/

GitHub Pagesへは、`main`ブランチへの更新時にGitHub Actionsから自動配信します。公開先が変わっても、旅行や写真はGitHubへ送信されず、利用しているブラウザのIndexedDB内に保存されます。

旧URLとGitHub Pagesは保存領域が別です。移行時は、旧URLでZIPバックアップを保存してから新URLで復元してください。

## 開発

```text
pnpm install
pnpm dev
pnpm test
pnpm build
```

仕様と開発計画は `docs/` にあります。
